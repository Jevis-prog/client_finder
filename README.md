## Python 3.12

## Установка зависимостей

pip install -c pip/constraints.txt -r pip/requirements.txt

## Запуск

docker-compose up --build

1) Авторизуйтесь по номеру телефона https://my.telegram.org/auth.

2) Перейдите в раздел API Development tools. Откроется окно «Create new application». Заполните данные о вашем приложении. Вводить URL-адрес не нужно, только первые два поля (Название приложения и Короткое имя).
В конце нажмите Create application.

3) Появится окно с данными. Нам нужны API id и API hash их надо сохранить в .env как API_ID и API_HASH

4) Чтобы создать зашифрованную сессию введите команду python -m bot create-session. 
Скрипт попросит вас ввести пароль, который в дальнейшем будет использоваться для входа в бота. Далее введите данные от тг аккаунта (телефон, код, пароль(опционально)).
Сессия зашифруется и сохраниться.

5) Для получения списка чатов введите команду python -m bot chats, введите пароль который придумали при регистрации зашифрованной сессии. Вы увидете список своих чатов и их ID. ID чатов которые хотите прослушивать сохраните в .env файл в CHATS через запятую, пример "-12552354235, 246523453". 
Так же в .env файл в TARGET_CHAT_ID напишите ID чата в который бот будет пересылать лиды.

6) Введите команду python -m bot run, авторизуйтесь по заданному вами паролю и бот успешно запуститься.
